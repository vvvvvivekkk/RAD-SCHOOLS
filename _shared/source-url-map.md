# Source URL map

Every file in `ai/`, `robotics-iot/` and `drone/` has its canonical
source URL recorded in `_shared/download-manifest.md`.

Per-folder READMEs under each leaf directory show the source map
scoped to that folder.

## Verticals

- `/ai/` — AI curriculum sources (CBSE, SCERT TG, ICSE, NCERT, international, platforms, research, assessment)
- `/robotics-iot/` — Robotics + IoT sources (Arduino, RPF, LEGO, VEX, STEMROBO, Avishkaar, Tinkerly, ROS, CMU curricula)
- `/drone/` — Drone sources (DGCA, DJI, DroneBlocks, Marut, India Drone Academy, DroneDeploy, Pix4D)
